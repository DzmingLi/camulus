#+title: Transfer from Gnus, Elfeed and mu4e

大写和小写键有不同含义。正文和列表各自有绑定，具体后端还可以在相应界面注册操作。这里记录 Camulus 提供的绑定及其参考来源。

* 从 Gnus、Elfeed 和 mu4e 延续的操作
| Camulus 按键          | 使用位置和作用                                                 | 来源                                                                                        |
|-----------------------+----------------------------------------------------------------+---------------------------------------------------------------------------------------------|
| =C=                   | 首页或收件箱视图用默认账户写邮件，组内按当前组撰写                         | 沿用 mu4e 的大写 =C=（Compose）。组内使用当前组的习惯来自 Gnus。                            |
| =n=                   | 正文中跳到下一条已加载的未读消息                               | 对应 Gnus Summary 的 =n= 跳到下一条未读消息。                                               |
| =R=                   | 在提供该键的列表或正文里回复                                   | 沿用 mu4e 的大写 =R=（Reply）。                                                             |
| =RET=                 | 在组目录进入组，在内容列表打开所选内容                         | 进入组沿用 Gnus Group 的操作；列表打开正文对应 mu4e Headers 的 =RET=。                      |
| =b=                   | 在内容列表或正文用浏览器打开光标所在条目的原文                 | [[https://github.com/emacs-elfeed/elfeed#viewing-entries][Elfeed]] 的 =b= 打开当前条目的网页。 |
| =r= / =m=             | 按规则标记归档 / 手动选择目的地并标记                          | 借鉴 mu4e 的规则归档（Refile）和手选目的地（Move）。                                         |
| =d= / =u= / =x=       | 标记移除、撤销当前标记、执行当前视图中的全部标记                 | 沿用 mu4e 先标记再执行的交互。                                                               |
| =C-c C-c=             | 编辑草稿时发送                                                 | 沿用 Emacs Message 的发送键，Gnus 和 mu4e 都采用这个约定。                                  |
| =C-c C-d= / =C-c C-k= | 编辑草稿时保存并关闭                                           | 对应 mu4e 的保存草稿并离开、关闭编辑 buffer 后保留草稿。Camulus 的两个键都保存当前编辑。    |

Gnus 撰写键的引入见 [[https://github.com/DzmingLi/camulus/commit/104c084][提交 104c084]]。上游绑定见 [[https://www.gnu.org/software/emacs/manual/html_mono/gnus.html][Gnus 手册]]、[[https://www.gnu.org/software/emacs/manual/html_node/message/Sending.html][Emacs Message 手册]]、[[https://www.djcbsoftware.nl/code/mu/mu4e/Keybindings.html][mu4e 列表按键]] 和 [[https://www.djcbsoftware.nl/code/mu/mu4e/Composer-Keybindings.html][mu4e 编辑按键]]。

* Refile 规则

=camulus-refile-rule= 可以是固定的收藏夹路径，也可以是一个接收条目 plist 的函数。按 =r= 时调用函数并记录目的地，按 =x= 时才开始归档。函数的返回值见下表。

| 返回值                              | 目的地 |
|-------------------------------------+--------|
| ="Reading/Work"=                    | Camulus 收藏夹，支持嵌套路径。 |
| =(:file PATH :format html)=         | 本地 HTML 文件，=text= 导出纯文本。省略格式时用纯文本。 |
| =(:file PATH :format FUNCTION)=     | 函数接收条目 plist 和按时间排序的消息 alist 列表，返回要写入文件的字符串。 |
| =nil=                               | 交给后端规则。两者都未匹配时，=m= 可临时选择目的地。 |

条目 plist 提供 =:backend=、=:backend-key=、=:group=、=:groups=、=:kind=、=:id=、=:title=、=:author= 和 =:url=。消息 alist 提供 =id=、=parent_id=、=title=、=author=、=created=、=url=、=body= 和 =html= 等字段。导出只写正文和元数据，目标父目录须存在，已有文件会报错。列表导出整条讨论，在正文处导出当前一楼。

#+begin_src emacs-lisp
(setopt camulus-refile-rule
        (lambda (item)
          (when (equal (plist-get item :group) "reading")
            (list :file (expand-file-name
                         (concat (secure-hash 'sha256 (plist-get item :id)) ".html")
                         "~/Documents/")
                  :format 'html))))
#+end_src

邮件文件夹规则见 [[file:MAIL.org::*邮件归档][邮件归档]]。

=m= 的候选以类型标注。选 =Favorites: …= 会保存收藏副本，直接键入新名字可创建收藏夹。只有支持移动的条目才会看到自己的后端文件夹，选中后由该后端执行移动。

* 编辑和草稿
按 =C= 打开草稿后，可以在编辑缓冲区修改目的地字段。

| 后端      | 目的地字段  | 示例                                             |
|-----------+-------------+--------------------------------------------------|
| 邮件      | =To:=       | =To: alice@example.org=                           |
| Discourse | =Discourse:= | =Discourse: https://forum.example.org=             |
| Discourse | =Category:=  | =Category: 12=                                    |
| Reddit    | =Subreddit:= | =Subreddit: ocaml=                                |
| 豆瓣      | =Douban:=    | =Douban: 榜单图书鉴评中心 / 广播=                  |
| 豆瓣小组  | =Category:=  | =Category: 拔草=                                   |

在目的地字段中按 =C-M-i= 补全。邮件从本地 mu 联系人索引取地址，Discourse 提供已认证站点和当前站点的已知分类 ID，Reddit 提供已注册或订阅的 subreddit，豆瓣提供已注册小组、广播和当前小组的分区。邮件的 =To:= 可填多个地址。豆瓣可在一次提交中把小组帖子同步到广播。

| 按键                  | Camulus 操作                       |
|-----------------------+------------------------------------|
| =C-x C-s= / =C-c C-s= | 立即保存草稿。编辑时也会自动保存。 |
| =C-c C-c=             | 发送邮件、发表帖子或提交回复。     |
| =C-c C-d= / =C-c C-k= | 保存草稿并关闭编辑窗口。           |
