#+title: Transfer from Gnus / mu4e

大写和小写键有不同含义。正文和列表各自有绑定，具体后端还可以在相应界面注册操作。这里记录 Camulus 提供的绑定及其参考来源。

* 从 Gnus 和 mu4e 延续的操作
| Camulus 按键          | 使用位置和作用                                                 | 来源                                                                                        |
|-----------------------+----------------------------------------------------------------+---------------------------------------------------------------------------------------------|
| =m=                   | 收件箱、组列表、正文和组目录中新建邮件                         | Gnus 的 =m= 写邮件。                                                                        |
| =a=                   | 收件箱、组列表、正文和组目录中按当前组撰写。首页可以选择目的地 | Gnus 的 =a= 在组里发帖，Camulus 扩展成按组选择撰写方式。                                    |
| =n=                   | 正文中跳到下一条已加载的未读消息                               | 对应 Gnus Summary 的 =n= 跳到下一条未读消息。                                               |
| =r=                   | 在支持回复的正文里回复，邮件组的列表也提供该键                 | 对应 Gnus Summary 的 =r= 回复。mu4e 的回复键是大写 =R=。                                    |
| =RET=                 | 在组目录进入组，在内容列表打开所选内容                         | 进入组沿用 Gnus Group 的操作；列表打开正文对应 mu4e Headers 的 =RET=。                      |
| =d=                   | 在首页或邮件组中将选中的邮件移入 Trash                         | 对应 mu4e 的移入垃圾箱操作。mu4e 用 =d= 标记、=x= 执行；Camulus 按一次 =d= 就提交后台移动。 |
| =C-c C-c=             | 编辑草稿时发送                                                 | 沿用 Emacs Message 的发送键，Gnus 和 mu4e 都采用这个约定。                                  |
| =C-c C-d= / =C-c C-k= | 编辑草稿时保存并关闭                                           | 对应 mu4e 的保存草稿并离开、关闭编辑 buffer 后保留草稿。Camulus 的两个键都保存当前编辑。    |

Gnus 撰写键的引入见 [[https://github.com/DzmingLi/camulus/commit/104c084][提交 104c084]]。上游绑定见 [[https://www.gnu.org/software/emacs/manual/html_mono/gnus.html][Gnus 手册]]、[[https://www.gnu.org/software/emacs/manual/html_node/message/Sending.html][Emacs Message 手册]]、[[https://www.djcbsoftware.nl/code/mu/mu4e/Keybindings.html][mu4e 列表按键]] 和 [[https://www.djcbsoftware.nl/code/mu/mu4e/Composer-Keybindings.html][mu4e 编辑按键]]。

* 收件箱、组目录和阅读
| 按键                | 位置和作用                                                                                                  |
|---------------------+-------------------------------------------------------------------------------------------------------------|
| =M-x camulus= / =h= | 打开或返回个人收件箱。                                                                                      |
| =B= / =G=           | 在收件箱和组列表中打开组目录 / 通过补全选择组。                                                             |
| =b=                 | 在首页打开当前来源的浏览入口。                                                                              |
| =g=                 | 刷新当前列表或目录。                                                                                        |
| =n=                 | 在内容列表加载下一页；在正文跳到下一条已加载的未读消息。                                                    |
| =C-c C-k=           | 在内容列表取消当前加载任务。                                                                                |
| =RET=               | 打开光标处的内容、组或文件夹。                                                                              |
| =TAB= / =S-TAB=     | 在组目录、订阅面板或收藏夹目录移动到下一个 / 上一个按钮。                                                   |
| =+=                 | 在普通列表或正文选择收藏夹。列表可收藏整条讨论，正文可收藏光标所在的一楼。                                  |
| =f=                 | 打开收藏夹目录。                                                                                            |
| =d=                 | 普通列表移除当前进展；收藏夹内移除当前收藏归属。来源特有行为见下文。                                        |
| =D=                 | 在收藏夹内容列表删除当前文件夹。                                                                            |
| =U=                 | 打开订阅面板。                                                                                              |
| =p= / =P=           | 在订阅面板设置来源优先级 / 在首页选择显示的优先级。                                                         |
| =s= / =S=           | 内容列表的 =s= 管理当前内容的订阅或追踪，=S= 管理当前组的订阅。在组目录或订阅面板，两键都针对光标处的来源。 |
| =T=                 | 打开支持此功能的后端的远端话题追踪面板。                                                                    |
| =C=                 | 在内容列表编辑阅读器配置，在组目录编辑浏览入口配置。                                                        |
| =e=                 | 查看首页的来源刷新错误。                                                                                    |

追踪面板中，=RET= 打开条目，=s= 修改追踪级别，=/= 选择筛选条件，=g= 刷新，=n= 加载下一页，=q= 关闭窗口。

* 编辑和草稿
| 按键                  | Camulus 操作                       |
|-----------------------+------------------------------------|
| =C-x C-s= / =C-c C-s= | 立即保存草稿。编辑时也会自动保存。 |
| =C-c C-c=             | 发送邮件、发表帖子或提交回复。     |
| =C-c C-d= / =C-c C-k= | 保存草稿并关闭编辑窗口。           |

* 后端及视图专用绑定
| 后端或视图          | 按键                         | 操作                                                                                      |
|---------------------+------------------------------+-------------------------------------------------------------------------------------------|
| 邮件正文            | =A=                          | 打开当前这封邮件的附件面板。                                                              |
| 邮件列表或正文      | =C-c C-a=                    | 将邮件移入 Archive。mu4e 对应的操作是 =r= 标记 refile，再按 =x= 执行。                    |
| 邮件组列表          | =D=                          | 打开草稿组。草稿组中用 =RET= 恢复草稿，=m= 或 =a= 写新邮件。                              |
| 邮件附件面板        | =RET= / =o=、=s=、=S=、=q=   | 打开、保存当前附件、保存全部、关闭面板。                                                  |
| RSS / Atom 收件箱   | =d=                          | 删除本地副本并记录条目 ID。组内的 =d= 移除当前进展。                                      |
| Reddit 组列表或正文 | =+= / =-= / =0=              | 赞成、反对、取消投票。这两个视图的 =+= 优先执行投票，收藏可用 =M-x camulus-reader-save=。 |
| Discourse           | 列表 =c=，正文 =l= / =C-u l= | 选择分类，赞或取消赞。                                                                    |
| 豆瓣正文            | =l= / =L=                    | 赞或取消赞。                                                                              |
| GitHub 组列表或正文 | =F= / =M= / =v=              | 在 Forge 打开话题、打开本地 Magit status、进入 PR review。组列表用 =D= 打开草稿。         |

这些面板和后端快捷键的 Camulus 绑定分别在 [[../src/reader_ui.ml][阅读器]]、[[../src/backends/mu/attachments_emacs.ml][附件面板]] 和各后端的 Emacs 模块中注册。详见 [[file:MAIL.org][邮件]]、[[file:RSS.org][RSS]] 和 [[file:GITHUB.org][GitHub 与 PR review]]。
