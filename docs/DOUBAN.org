#+title: 豆瓣

* 豆瓣小组

从组目录中的「豆瓣」进入已注册的组，也可用 =M-x camulus-douban-group= 临时浏览。命令接受小组主页或讨论区链接、数字 ID 或短名。组列表按 =n= 载入下一页，按 =RET= 打开帖子正文和回复树。

在 =camulus-groups= 中加入这样的条目即可注册一个浏览入口：

#+begin_src elisp
((name . "榜单图书鉴评中心") (backend . "douban") (group . "group.728965"))
#+end_src

把同一个组标识加入 =camulus-douban-subscriptions= 可在收件箱接收小组更新。组列表通过 =/rexxar/api/v2/group/ID/topics= 读取，并根据豆瓣返回的分页信息继续取下一页。帖子正文取自 =/rexxar/api/v2/group/topic/ID=，沿用 =group-topic:ID=，与从广播和通知打开的同一帖子共享已读和收藏。需要组员权限的小组使用 Firefox 中已登录的豆瓣账号。

* 撰写

在小组列表中按 =c= 可选一个分区，或选 =All categories= 返回全组。分区列表通过 =topic_tag_id= 分页。

在豆瓣组里按 =C= 撰写。在分区里撰写会预填当前分区 ID，同一小组的不同分区各自保留草稿。小组入口预填当前小组，其他豆瓣入口预填广播。标题和正文可以编辑。在 =Douban:= 行按 =C-M-i= 补全已注册的小组及广播：

| =Douban:= 的值          | 发布目标       |
|-------------------------+----------------|
| =榜单图书鉴评中心=      | 只发到小组     |
| =广播=                  | 只发广播       |
| =榜单图书鉴评中心 / 广播= | 同步发到两处   |

小组也可以用 ID、短名或链接指定。双发使用豆瓣网页编辑器的同一个发布请求，启用 =send_status=。账号和发帖权限沿用 Firefox 登录。=C-c C-c= 提交，=C-c C-d= 保存并关闭草稿。

=Category:= 是可选的小组分区。可以填名称或分区 ID，按 =C-M-i= 补全当前小组提供的分区。小组和广播双发时，分区只应用于小组帖子。单独发广播时可留空。

* 点赞和正文

阅读在线广播、帖子或某一楼评论时，顶部提供「赞 · l」「取消赞 · L」按钮，也可按 =l= / =L=。操作针对光标所在楼层；不能给未加载、不可用的楼层或离线归档直接点赞。

后端实现 =Backend.Liking=。每次操作立即发请求，收到确认才更新 ♥ 标记；失败直接报错，不加入离线队列、不自动重试。同一楼的请求未结束前不能重复提交。超时无法证明服务器未执行，界面提示刷新确认远端状态。较早发起的读取结果不会覆盖刚确认的操作；后续刷新仍以远端为准。

登录沿用公共 Firefox Cookie provider。只把匹配目标 URL 的 Cookie 发给豆瓣固定 HTTPS 地址。浏览器数据库中没有 =ck= 时，使用相同账号请求 =/mine/=，取出返回的 CSRF token，仅用于本次请求，不写回 Firefox、不保存独立会话。写请求不跟随重定向。

接口依据豆瓣网页当前使用的代码（2026-11-07）核对：

- [[https://asset.doubanio.com/cuphead/sns-static/status/656.c.70cdb.a.js][广播页面脚本]]：=POST /j/status/like=、=POST /j/status/unlike=，传 =sid= 和 CSRF header。
- [[https://asset.doubanio.com/cuphead/vendors/js/actions/react_btn.7073482b761e.js][帖子 reaction 按钮]]：=POST /rexxar/api/v2/group/topic/ID/react=，显式传 =reaction_type=1= 或 =0=。
- [[https://asset.doubanio.com/cuphead/sns-static/comments/747.c.0a047.a.js][评论脚本]]与页面 =_COMMENTS_CONFIG=：广播评论使用 =status/comment/ID/react=；帖子评论使用 =group/topic/TOPIC/comment/COMMENT/react=。

帖子正文的富文本段落依赖网页 CSS 保留原始换行。后端把段落文本节点中的换行转成 =<br>=，保留空行、嵌套行内格式与预格式化代码，不把 HTML 源码缩进变成额外空段落。
