#+title: Camulus

Camulus 是 Emacs 的统一阅读器，把邮件、论坛讨论和个人订阅放进同一个界面。它延续 [[https://www.gnu.org/software/emacs/manual/gnus.html][Gnus]] 的分组与讨论串阅读方式，借鉴 [[https://github.com/emacs-elfeed/elfeed][Elfeed]] 的订阅阅读体验，以及 [[https://www.djcbsoftware.nl/code/mu/mu4e/Bookmarks-and-Maildirs.html][mu4e]] 的主界面和操作方式。

需要 *Emacs 31*。

* 核心抽象
** 后端
后端接入一种服务或数据格式，提供浏览和阅读能力。一个后端可以提供多个 group 和订阅源。

** Group
Group 是后端提供的浏览入口，由后端定义如何定位。刷新组会拉取列表，打开条目时按需加载正文和回复。用 =camulus-groups= 注册后，可从首页配置的视图或组目录进入。

** 订阅源
订阅源为个人收件箱提供文章和讨论的新进展，可以来自一个选定的 group，也可以来自个人通知流。订阅同步负责把正文和完整回复树保存到本地，随后打开条目即可读取。当前部分讨论仍在打开时加载完整回复树。[[file:docs/ENTRIES.org][浏览入口与订阅配置]]

** View
首页列出可配置的视图，并显示本地未读数和总数。视图可以筛选收件箱、打开一个浏览组或进入一个收藏夹。订阅决定同步哪些内容，视图决定打开哪些内容。

** Refile
Refile 按用户的规则为条目选择归档去向，例如收藏夹、后端文件夹或本地导出文件。按 =r= 根据规则打标记，按 =x= 执行。[[file:docs/transfer-from-gnus-and-mu4e.org::*Refile 规则][配置 Refile 规则]]

** Move
Move 用于手动指定条目的目的地。按 =m= 选择文件夹并打标记，按 =x= 执行。通用收藏夹可以保存任意后端的内容；后端文件夹只接收所属后端允许移动的条目。

* 阅读与内容管理
- =M-x camulus= 或 =h= 打开首页。默认用 =i= 查看未读、=a= 打开全部订阅的时间线。用 =V= 选择视图，=B= 浏览组，=U= 查看订阅。
- =RET= 在右侧打开文章或完整回复树，并转移焦点。树默认展开，同级回复按时间正序排列，定位第一条已加载的未读内容；渐进加载保留阅读位置。
- =b= 在列表或正文中用浏览器打开当前条目的原文。
- 已读只表示正文进入过可见区域。按 =d= 标记当前进展待移除，按 =x= 执行，按 =u= 撤销待执行标记。移除后保留订阅，后续新进展可以再次出现。
- 远端刷新把新条目和更新合并到本地组列表。旧条目即使滚出远端的最新页面，也继续留在组里。
- 收藏会持久保存正文和归档资源，支持嵌套收藏夹、同一内容加入多个收藏夹，以及分别收藏整条讨论和单独一楼。按 =f= 或点击顶部 =[Folders · f]= 浏览收藏。收藏可离线阅读。
- 普通列表中的收藏条目显示为红色。
- 阅读界面内嵌显示正文图片，支持 [[file:docs/WEBKIT.org][内联视频]] 和 Olivetti 排版。

各界面的绑定和按键来源见 [[file:docs/transfer-from-gnus-and-mu4e.org][快捷键与迁移指南]]。

* 使用 Nix 安装
也可直接加入自己的 Nix flake：

#+begin_src nix
inputs.camulus.url = "github:DzmingLi/camulus";
inputs.camulus.inputs.nixpkgs.follows = "nixpkgs";

# 在已有的 emacsWithPackages 调用中：
emacsWithPackages (epkgs: [
  (inputs.camulus.lib.mkEmacsPackage epkgs)
])
#+end_src

* 配置
使用 =M-x customize-group RET camulus= 管理组选项和后端设置。也可以直接在 Emacs 配置中设置。

首页正文中的每个入口都可以点击或按 =RET= 打开。用 =camulus-home-actions= 设置常用命令、排列顺序和快捷键，用 =camulus-home-views= 定义常看的视图。首页按 =C-c e= 可一起编辑这两项。[[file:docs/ENTRIES.org][视图、浏览入口与订阅配置]]

默认状态数据库为 =~/.local/state/camulus/state.sqlite3=，遵循 =XDG_STATE_HOME=。已读、收件箱进展、收藏归属和正文归档分别持久保存。阅读时可以先展示本地内容，收藏条目可离线打开。
